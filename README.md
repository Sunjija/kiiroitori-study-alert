# 키이로이토리 공부 알리미

알바 일정과 공부 블록을 함께 보여 주는 오프라인 HTML 학습 플래너입니다. 영어·행정법·행정학이 거의 노베이스인 2027년 지방직 일반행정 9급 준비를 기준으로, 강의·백지 복습·기출·저녁 복습을 단계별로 조정할 수 있게 만들었습니다.

## 바로 사용하기

1. 저장소의 `index.html`을 GitHub Pages로 배포하거나 파일로 내려받아 Chrome·Edge에서 엽니다.
2. 상단 `학습 계획`에서 학습 시기와 주간 분량을 고릅니다.
3. 미리보기를 확인한 뒤 `이 계획을 시간표에 적용`을 누릅니다.
4. `편집`에서 매주 요일 또는 특정 날짜의 일정을 바꿀 수 있습니다.

기본 분량은 주 36시간 20분이며, 선택 가능한 증량 단계는 주 40시간·44시간·48시간입니다. 날짜가 되었다고 자동으로 증량하지 않습니다. 시간표 밖의 늦은 시간에는 새 강의보다 FSRS/Anki·단어·표시한 오답처럼 가벼운 복습을 권장합니다.

## GitHub Pages

저장소의 **Settings → Pages**에서 `Deploy from a branch`, `main`, `/ (root)`를 선택하면 `index.html`을 정적 사이트로 배포할 수 있습니다. 이 앱은 서버와 빌드 도구가 필요하지 않습니다.

## 기능

- 반응형 시간표: PC·태블릿·모바일에서 시간·과목·상태를 확인
- 현재 일정·다음 일정·마감 카운트다운과 화면 알림
- 학습 단계와 주간 분량 선택: 36시간 20분 → 40시간 → 44시간 → 48시간
- 전공 A/B 요일 배치, 한능검 취득 후 시간 전환, 날짜별 예외 편집
- 프리텐다드·박다현체, 도서관·카페 캐릭터 테마, 사용자 에셋 팩
- JSON 백업·복원과 Markdown 시간표 내보내기
- 네트워크 없이 실행되는 단일 HTML 빌드 제공

## FSRS 적용안

`FSRS_적용방안.md`에 영어 단어·전공 개념·기출 오답을 FSRS 복습 항목으로 만드는 방법과 HTML 시간표에 연결하는 설계를 정리했습니다. 현재 저장소에는 단계별 시간표가 구현되어 있고, FSRS 카드 엔진과 복습 기록은 별도 통합 대상입니다.

## 파일 안내

- `index.html`, `style.css`, `app.js`, `engine.js`, `plan.js`, `data.js`: 수정 가능한 소스
- `키이로이토리_공부알리미.html`: 폰트·이미지·코드를 모두 포함한 단일 실행 HTML
- `assets/`: 캐릭터 이미지, 폰트, 라이선스
- `학습계획_2027.md`: 시기별 공부 내용과 증량 규칙
- `FSRS_적용방안.md`: FSRS와 시간표 연결 설계
- `사용방법.md`: 설치·편집·백업·알림 사용법

캐릭터 이미지는 AI 생성 이미지이며 공식 배포 이미지가 아닙니다. 글꼴 라이선스는 `assets/fonts/OFL.txt`와 `assets/FONT_LICENSE.txt`를 확인하세요.
